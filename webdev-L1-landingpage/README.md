# AutoConnect - Landing Page

## Project Overview

AutoConnect is a landing page concept designed for a lost-and-found
platform that helps passengers reconnect with auto drivers and recover
belongings left behind during their journey.

## Objective

The objective of this project is to create a clean, responsive and
visually polished landing page using HTML5 and CSS3.

## Technologies Used

- HTML5
- CSS3

## Features

- Sticky navigation bar
- Hero section
- Call-to-action buttons
- How It Works section
- Features section
- Responsive design
- Footer with social links
- Mobile-friendly layout
